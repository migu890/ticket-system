# Ticket System

Webbasiertes Ticket-System zur Erstellung und Verwaltung von Support-Tickets.

## Technologien

### Frontend
- Vue 3
- TypeScript
- Vue Router
- Vite

### Backend
- Node.js
- TypeScript
- Hono
- Prisma

### Datenbank
- PostgreSQL

### Testing
- Vitest
- Vue Test Utils

### DevOps
- Docker
- GitHub Actions
